## Top 5 — what they do well
1. **HTX Web Works** — reframes the sale: "You don't have a website problem, you have a system problem." Strongest positioning in the set; one CTA (20-minute strategy call).
2. **Mako Studio** — technical credibility through specifics (schema, Core Web Vitals, CSP, WAF) and city landing pages.
3. **Chelle Builds** — one featured product shown all the way through; honest "currently building" list. Solo voice reads as trustworthy.
4. **A&G Legacy** — "Proof, not promises": real Search Console numbers from its own brand, with dates.
5. **UX Pros** — clean four-pillar service structure; "Design, Build & Automate."

## Patterns: elite vs average
- Elite sites name a **problem** before a service; average sites list services.
- Elite proof is **specific and dated**; average proof is counters that render as "0+" (UX Pros, Nuesion, Dele Giwa all show broken zero counters in text).
- Inflated or unverifiable claims (Houston Web Design's "200+ projects", Nuesion's "100+ team") read as template filler.
- **Nobody in the set uses a signature visual object.** Copy-wise, none mention a scroll-driven or product-style reveal. Average register is generic dark-tech or stock imagery.

## Gap for The Roy Effect
A recognisable emblem, a solo owner, and an honest voice. A scroll-stop reveal of the seal — each layer mapped to one thing Rory builds — gives a signature moment no local competitor has, without needing any invented numbers.
